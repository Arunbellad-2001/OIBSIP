# Oasis Infobyte Data Science Internship

## About the Internship

This repository contains the projects completed during my Data Science Internship at Oasis Infobyte.

During this internship, I worked on data analysis, data visualization, data preprocessing, and machine learning models using Python.

The repository contains the following three projects:

1. Iris Flower Classification
2. Unemployment Analysis in India
3. Car Price Prediction Using Machine Learning

## Technologies Used

* Python
* Jupyter Notebook
* Pandas

* Matplotlib

* Scikit-learn
* Machine Learning
* Data Analysis
* Data Visualization

## Projects

### Task 1: Iris Flower Classification

**Folder:** `DataScience-Task1-IrisClassification`

In this project, I used the Iris dataset to build a machine learning classification model.

The project includes:

* Loading the Iris dataset
* Understanding the dataset
* Checking missing values
* Splitting the data into training and testing sets
* Training classification models
* Comparing model accuracy
* Evaluating the model results

The following models were used:

* Logistic Regression
* Random Forest Classifier

The Logistic Regression model achieved an accuracy of approximately **96.67%**.

### Task 2: Unemployment Analysis in India

**Folder:** `DataScience-Task2-UnemploymentAnalysis`

In this project, I analyzed unemployment data in India.

The project includes:

* Loading the unemployment dataset
* Checking the shape and columns
* Checking missing values
* Converting date columns
* Performing statistical analysis
* Finding unemployment rates by region
* Analyzing unemployment trends
* Creating charts and visualizations
* Studying the relationship between unemployment rate and labour participation rate

The project helped me understand how data analysis and visualization can be used to study unemployment patterns in India.

### Task 3: Car Price Prediction Using Machine Learning

**Folder:** `DataScience-Task3-CarPricePrediction`

In this project, I built machine learning regression models to predict the selling price of used cars.

The dataset contains information such as:

* Car name
* Manufacturing year
* Present price
* Selling price
* Kilometers driven
* Fuel type
* Seller type
* Transmission
* Number of previous owners

The project includes:

* Loading the car dataset
* Checking data types
* Checking missing values
* Checking duplicate records
* Performing statistical analysis
* Exploring numerical and categorical columns
* Creating a new `Car_Age` feature
* Performing exploratory data analysis
* Applying one-hot encoding
* Splitting the data into training and testing sets
* Training regression models
* Comparing model performance
* Predicting the selling price of a sample car

The following models were used:

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

The Linear Regression model performed best among the tested models with an R-squared score of approximately **0.753**.
